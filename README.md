# Student Task Hub

Create a simple, clean, responsive Student Task Tracker web application with localStorage persistence. Include a dashboard with summary cards (Total, Completed, Pending), an add task form with title and optional due date (disallow empty tasks), a task list with completion checkboxes and delete buttons, filter tabs (All, Pending, Completed), and a friendly empty state. Keep the design student-friendly, clean, and fully functional without requiring a backend or login.
