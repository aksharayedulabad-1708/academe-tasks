# 🎓 Student Task Tracker

> **Plan it. Track it. Complete it. 🚀**

A simple, clean, and responsive task management web application designed especially for students to organize their daily academic and personal tasks.

The **Student Task Tracker** allows users to add tasks, set due dates, track their progress, filter tasks, and keep their tasks saved even after refreshing the browser.

---

## ✨ Features

### 📝 Task Management

* ➕ Add new tasks
* 📅 Set an optional due date
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 🚫 Prevent empty tasks from being added

### 📊 Task Dashboard

The dashboard provides a quick overview of:

* **Total Tasks**
* **Completed Tasks**
* **Pending Tasks**

### 🔍 Task Filtering

Easily organize your tasks using:

* **All** — View every task
* **Pending** — View unfinished tasks
* **Completed** — View finished tasks

### 💾 Persistent Storage

Tasks are stored using **Browser Local Storage**, so your tasks remain available even after refreshing or reopening the page.

### 📱 Responsive Design

The application works smoothly on:

* 💻 Desktop
* 💻 Laptop
* 📱 Mobile
* 📲 Tablet

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/student-task-tracker.git
```

### 2. Open the project

```bash
cd student-task-tracker
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open the local URL shown in your terminal, usually:

```text
http://localhost:5173
```

## 🎯 How It Works

The application follows a simple workflow:

```text
Add Task
   ↓
Task appears in the Task List
   ↓
Mark task as Completed
   ↓
Dashboard statistics update
   ↓
Filter tasks
   ↓
Delete tasks when finished
```

All task information is stored in the browser using **Local Storage**.
